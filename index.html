PROJECT 01

Document Q&A Assistant

Intelligent RAG Application with Agent Tools.

View on GitHub

Built an intelligent document question-answering system that allows users to upload PDF, TXT and Markdown files and ask questions using Retrieval-Augmented Generation.

  • Semantic search using bge-small-en-v1.5 embeddings.
  • PostgreSQL with pgvector and HNSW indexing.
  • Document chunking with page-level citations.
  • Hallucination reduction using similarity thresholds and NOT_FOUND fallback.
  • LLM-powered create_ticket tool with Pydantic validation.
  • HMAC-SHA256 signed and idempotent webhooks.
  • Background task processing.
  • Automated testing with mocked LLM responses.
  • GitHub Actions CI with pgvector service container.
